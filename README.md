# Braveball Prototype

一个使用 Godot 4.6 制作、搭配原创圆形角色素材和中世纪魔法主题界面的弹球战斗原型，用于验证：

- 勇者本身就是弹球；
- 进入 `1-1` 前通过独立的战旗轮盘选择一项全局战斗风格：中央展示完整能力，左右战旗用于切换预览，最后必须用按钮或 Enter 确认；它与过关后的三张升级卡使用不同结构。三个风格为 `钢铁誓言`（勇者直接撞击敌人时获得 2 点护盾，每球最多 20 点）、`重击`（累计 3 次直接撞击后蓄好，下一次直接撞击伤害提高 40%，命中后立即消耗）或 `怒火核心`（每次直接撞击额外获得 5 点战意）；飞斧、爆炸等次生伤害不会触发这些能力；
- `重击` 的累计次数会用勇者周围的三个光点显示，蓄好时勇者出现完整金色外圈；累计进度在每次掉球后重置，最多储存一次强化攻击；
- 左右挡板维持传统弹球操作；
- 挡板按照旋转速度与实际接触位置传递动量，尖端击球比转轴附近更强；
- 撞击敌人造成与速度档位相关的伤害；
- 桌面战斗符文调整为左侧 `MOMENTUM`（立即提高 30% 速度）和右侧 `WAR CRY`（下一次攻击伤害提高 40%）；所有技能符文都是可直接穿过的地面触发区，只在勇者进入范围时触发一次，不会因物理碰撞而反弹或被推出（`MOMENTUM` 与 `CHARGE` 仍会按技能说明主动加速）；原中央技能改为四条边均有真实碰撞的竖向菱形反射块，并下移、放大以填充中部空间；
- 两枚战斗符文不消耗能量，并分别具有 3 秒与 4 秒冷却；待使用的 `WAR CRY` 不能重复触发；
- 两侧固定斜板不再额外提供加速，改用摩擦抑制贴板滑动；上方两块斜板旋转后移到小怪斜下方，与怪物图标保持明确间距；
- 移除了意义不明确的中央大型装饰圆阵；交错地砖会严格裁切在球桌内部，不再渗入左右状态面板；
- 每次放球前可用鼠标连续控制勇者的水平落位，高度固定在 `GUARD / CHARGE` 一排；确认后勇者会从当前位置垂直向下掉落，让第一次上行动量来自玩家挡板；可选范围限制在两枚技能之间，并与所有怪物保持安全距离；
- 被动碰撞会损失速度；静止挡板只提供很弱的回弹，只有新一次按键产生的短暂挥击窗口能够主动给球补充能量；
- 左右挡板之间留有足够宽的漏球缺口；完全不操作时，勇者不会卡在挡板尖端，会在数秒内自然掉落；
- 优秀操作积累能量；
- 能量充满后，撞中桌面上的技能板块立即释放技能；
- `CHARGE` 板块触发 3 秒冲锋，`GUARD` 板块提供 25 点临时护盾；
- `GUARD` 与 `CHARGE` 的半径从 `34px` 缩小到 `25px` 并移到下层两侧；五个怪物全部保留，但两只近战怪已向桌面边缘移动，为中央留出自由飞行通道；
- 左右外墙进入底部漏球区前的斜面起点已从 `y=610` 下移至 `y=640`，形成更平缓的内导角度，让侧路落球更容易回到控制板覆盖范围；斜墙仍沿用普通墙面的弹性；
- 左右控制板由 `130px` 小幅加长至 `135px`，根部各向外移动 `5px`；内侧尖端和中央漏球口基本不变，外墙一侧的通道只比初版缩窄约 `4–5px`，保留明确的掉球风险；
- `1-1` 至 `1-5` 都移除了中央 V 形哥布林城门的画面和碰撞，避免勇者被夹在门板内；机关代码保留给后续地图重新设计；
- 勇者拥有 100 点生命和最多 50 点护盾；掉球后，所有存活敌人依次反击，护盾会优先吸收伤害；每通过一关会在奖励结算时恢复最多 10 点生命，但不会超过生命上限；
- 敌人反击时，当前出手的怪物会播放自己的动作，同时触发短促的全屏震动与红色边缘光晕，不再发射攻击射线；
- 当前流程扩展为 `1-1` 至 `1-5` 五个关卡：`1-1` 使用原第一关的普通小兵编制但移除中央菱形；`1-2` 完整恢复原第一关，中央菱形重新出现，上排仍是没有投射能力的普通哥布林小兵；
- `1-3` 使用原第二关的哥布林法师编制，并以一只中央近战哥布林替换菱形，因此共有六名敌人；`1-4` 恢复原第二关的五名敌人与中央菱形；`1-5` 移除菱形和上方队长，改为中央哥布林军阀、上方两名法师与下方两名战士；
- `1-3` 至 `1-5` 上排两只普通小兵替换为哥布林法师：保持容易命中的碰撞尺寸，但生命更低、基础攻击为 8，其中 50% 伤害直接穿透护盾；紫色法帽、法杖、外圈和攻击特效用于快速识别；
- 哥布林军阀拥有 150 点生命和 10 点初始攻击。四只小怪各维持一面绕军阀缓慢旋转的实体护卫盾，勇者直接撞上会被弹开；爆炸、飞斧和尖刺属于战技伤害，可以越过盾阵。任意小怪死亡时对应盾牌碎裂，同时让军阀恢复最多 15 点生命，并获得一层基础攻击 `+15%` 的怒气；四层按加法累计至 `+60%`。盾牌碎裂、吸血轨迹、红色光环、四枚怒气标记与悬浮信息会同步显示状态；军阀若已在同次伤害中死亡则不会复活；
- 放球前将鼠标悬浮在任意怪物、战斗符文或下层 Fury 技能图标上，会显示生命、攻击、消耗、冷却和能力说明；正式弹球阶段自动隐藏信息卡；
- 过关奖励按阶段分池：`1-1` 解锁战斗技艺，`1-2` 战技强化，`1-3` 基础训练，`1-4` 再次选择战斗技艺或强化，`1-5` 为本轮终点；机制牌和数值牌会在战技强化池中共同参与抽取，并用卡牌类型文字明确区分，避免某一类增益在后期没有可选项；
- `RUNE BLAST` 与 `THROWING AXE` 的基础冷却均为 10 秒且彼此独立。爆炸可由墙、固定板、菱形或敌人触发，但不会被玩家控制的左右挡板触发；飞斧仍可由包括控制板在内的真实反弹触发。可穿透的地面符文不算反弹；
- 爆炸可以升级伤害（每级按基础值 `+25%`）、范围（每级 `+20%`，最多三级）和冷却；飞斧可以升级伤害（每级 `+25%`）、同时投掷数量和冷却；冷却每级减少基础值的 `10%`，即固定减少 1 秒，最低可以达到 1 秒；
- 三种战技都增加了一张一次性机制升级：`MARCHING AFTERSHOCK` 会在符文爆炸 0.4 秒后，以勇者当时所在位置（而非第一次爆点）再造成一次 40% 伤害、70% 范围的爆炸；`RETURNING AXE` 命中首个目标后会动态追随移动中的勇者返回，返程可对另一名敌人造成 60% 伤害；`SHIELD BASH` 让勇者直接撞击按当前每 10 点护盾获得 +1 伤害，最多 +5，且不会消耗护盾；
- `SPIKED SHIELD` 基础反弹实际格挡伤害的 50%；`SHARPENED SPIKES` 每级使所有尖刺伤害提高 25%，`SCATTERING BARBS` 每级增加一个 220px 内的飞散目标，`SHIELDBREAK RETORT` 则在每次敌人阶段第一次破盾时对全部存活敌人造成低伤害；
- 护盾成长与尖刺机制相互独立：`SHIELD TRAINING` 每级使所有护盾获取量提高 25%，并用小数累积保证钢铁誓言的低数值也能受益；`HOLD THE LINE` 一级保留回合后剩余护盾的 25%，之后每级增加 10%，最终可以达到 100%；
- 两侧面板都会显示当前关卡，右侧还会显示已获得成长，以及爆炸、飞斧等成长的实时冷却；
- 已加入独立交互音效：墙壁碰撞、挡板击球、击打怪物、五种技能、爆炸、飞斧、勇者受击与护盾格挡；`1-1` 至 `1-4` 循环播放 `Odin Approaches`，进入 `1-5` Boss 战时自动切换为 `Hard Fight Action`，普通关之间不会重新从头播放。

## 运行

在项目目录执行：

```sh
godot --path .
```

或者在 Godot Project Manager 中导入 `project.godot`。

## 操作

| 按键 | 功能 |
| --- | --- |
| `A` / 左方向键 | 左挡板 |
| `D` / 右方向键 | 右挡板 |
| 移动鼠标（放球前） | 调整勇者的水平落位；高度保持固定 |
| 悬浮怪物 / 技能（放球前） | 查看当前生命、攻击与技能规则 |
| 鼠标左键 / `Space` | 确认当前落位，并让勇者垂直向下掉落 |
| `1` / `2` / `3` 或鼠标 | 开局选择战斗风格；过关后选择成长 |
| `R` | 重新开始 |
| `F` | 原型调试：立即充满能量 |
| `K` | 原型调试：立即清空当前关卡，并正常进入过关/三选一流程 |

`F` 与 `K` 都是原型测试快捷键。正常情况下，撞击敌人和使用挡板会积累战意；`MOMENTUM` 与 `WAR CRY` 不消耗能量，各自拥有独立的短冷却。`WAR CRY` 和开局风格中的 `重击` 都只强化下一次有效敌人撞击，结算后立即消耗；两者同时蓄好时加成为可读的 `+80%`，不会相乘。

## 当前验证重点

这不是完整游戏，而是核心手感实验。第一轮试玩建议重点观察：

1. 球桌宽度是否适合横屏；
2. 敌人位于高、中、低频球路时是否都能合理命中；
3. 能量充满后，能否通过挡板有意识地选择 `GUARD` 或 `CHARGE`；
4. 冲锋速度是否紧张但仍可读；
5. 技能板块误触是否过多。

## 角色素材

`assets/warrior.png` 与 `assets/goblin.png` 是为本原型生成的原创透明圆形角色素材。美术层不会改变勇者球或敌人的圆形碰撞范围。

## 视觉主题

弹球桌现在是一座古堡中的魔法战场：地面使用严格限制在桌内的石砖，两枚战斗符文、两个能量技能板块与中央黄铜菱形组成主要目标；轨道与挡板使用木材和黄铜造型。左右状态区采用战旗、皮革、羊皮纸文字与铆钉边框。

## 攻击特效扩展

每个敌人数据都通过 `attack_effect` 选择攻击表现。当前关卡使用 `grunt_lunge`、`mage_cast` 和 `boss_slam` 三种配置，分别控制怪物动作时长与幅度、屏幕震动、红色光晕和粒子；代码中另保留未启用的远程后坐配置，供以后真正加入远程敌人时使用。后续增加新表现时，只需在 `_attack_effect_profile()` 注册配置、在 `_enemy_attack_draw_offset()` 添加对应动作，并让敌人选择该 ID；伤害与敌人回合逻辑无需修改。

## 交互音效

`assets/sfx/` 内包含十二个本项目程序合成的原创音效，以及玩家提供的受击、战吼和死亡素材。桌面技能不再复用同一声音：`WAR CRY` 使用 `war cry.wav`（来自 `Dwarf_Battle_Vocal_Battle_Cry_2.wav`），`MOMENTUM` 是两声清亮的“玲玲”铃响，`GUARD` 是空心木桶敲击，`CHARGE` 是拔剑加冲刺气流。成长选择、爆炸和飞斧也分别保留独立声音。

敌人无论被勇者直接撞击，还是被爆炸、飞斧或尖刺击杀，都会从统一的死亡入口播放音效：普通哥布林、战士和法师使用 `goblin_grump.wav`，`1-1` 至 `1-4` 的哥布林队长使用 `elite_goblin_die.wav`，`1-5` 哥布林军阀使用 `boss1_die.wav`。军阀因部下阵亡而增加怒气时暂时只播放盾碎、吸血轨迹与红色光环等视觉反馈，不再使用旧的低沉合成战吼。

播放使用八声部音效池，允许格挡与受击等声音叠加。墙壁碰撞会根据法线撞击速度调整音量和音高，并有极短的全局冷却，避免高速连续反弹产生刺耳的声音堆叠。

## 背景音乐

普通战斗使用用户提供的 `Odin Approaches.mp3`，裁掉原曲最前面的 15 秒后，在项目中命名为 `normal level.ogg`；播放和循环都会直接从原曲 `00:15` 开始，当前时长约 149 秒。第五关继续使用用户提供的 `Hard Fight Action.mp3`。两者都转换为高质量 Ogg Vorbis，以兼容当前 Godot 构建并减小打包体积。两首曲子都设置为循环播放，并使用独立音乐声部，不会占用交互音效的八个播放通道。考虑到原始母带响度不同，普通关音乐设为 `-18 dB`，Boss 音乐设为 `-19 dB`，以给碰撞、技能和战吼保留清晰空间。

## 命令行烟雾测试

```sh
godot --headless --path . -- --smoke-test
```

也可以验证完全不操作挡板时，勇者是否会自然掉入漏球区：

```sh
godot --headless --path . -- --passive-test
```

五关、分类三选一、最低 1 秒冷却、多斧头、尖刺反伤与余盾可用下面的自检命令验证：

```sh
godot --headless --path . -- --progression-test
```
